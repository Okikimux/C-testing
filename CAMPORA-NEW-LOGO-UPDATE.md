# CAMPORA logo update

The supplied new CAMPORA symbol has been installed as a square transparent PNG.

- `public/campusdrop-logo.png` is used by the site header and login screen.
- `public/campora-app-icon.png` is used for installed-app icons and Apple touch icon metadata.
- `public/favicon.png` is used as the browser favicon.
- `public/manifest.webmanifest` declares the square app icon.

The original `campusdrop-logo-original.png` asset has been preserved. This package applies the logo update only; it does not push changes to GitHub or deploy to Vercel.
